# Prima Take Perspective

A depth-placement audio plugin.

Core idea:
- Distance: moves a source perceptually near/far
- Focus: forward clarity
- Air: top-end perspective
- Reflections: early environment only, not a full reverb
- Width: stereo scale
- Mono Low: anchors low-end toward the center
- Mix / Output

Formats:
- VST3
- AU
- Standalone

macOS universal build via GitHub Actions.
